Download InkCanvasForClass CE ​

Get any version of ICC-CE here. The page automatically probes the Smart-Teach mirror and several GitHub proxies, then picks the fastest route available to you.

Which channel should I pick?

  • Beta (recommended): fastest updates and fixes, good for daily use
  • Preview: no pre-releases, more conservative than Beta
  • Stable: lowest release frequency, for scenarios demanding maximum stability
  • Nightly: untested Debug artifacts — do not use in a real classroom

See Installation & Update Channels for the full comparison.
