Settings Guide ​

Words: 0 words    Reading time: 0 min

ICC-CE offers a wide range of configuration options to suit different user needs. This guide will help you understand the functionality of each setting and find the optimal configuration.

Accessing Settings ​

Click the settings icon ⚙️ on the floating toolbar to open the settings panel.

General Settings ​

Startup Options ​

  • Run at startup: Set whether the application starts automatically with Windows.
  • Dock to sidebar after startup: Automatically minimize the toolbar to the side of the screen upon launching.
  • PowerPoint Support: Enable PowerPoint integration features.

Auto Update ​

  • Smart update: Enable the software to automatically check for updates.
  • Silent update: Automatically apply updates in the background during a specified idle period.
  • Time period: Set the hours during which automatic updates are permitted.

Canvas Settings ​

Pen Settings ​

  • Pen width: Adjust the thickness of the pen (2-30 pixels).
  • Highlighter width: Adjust the thickness of the highlighter.
  • Pen style: Choose between different writing styles:
    • Standard style: Uniform line thickness.
    • Calligraphy style: Line thickness varies depending on the drawing direction.

Eraser Settings ​

  • Eraser size: Choose between Small, Medium, Large, and Extra Large.
  • Eraser shape: Circle or Rectangle.

Touch Input ​

  • Show cursor: Display the cursor position while drawing.
  • Touch pressure mode: Simulate pressure sensitivity for touch screens.
  • Disable pressure sensitivity: Use a uniform thickness for all strokes.
  • Nib mode: Optimize inputs specifically for styluses/active pens.

Line Straightening ​

  • Auto-straighten straight lines: Enable/disable automatic line correction.
  • Length threshold: Set the minimum line length to trigger correction.
  • Sensitivity: Control the straightening algorithm threshold (0.05-2.0):
    • Low values (0.05-0.3): Requires the hand-drawn line to be very close to a straight line.
    • Medium values (0.3-1.0): Suitable for general use.
    • High values (1.0-2.0): More relaxed correction standard.

Endpoint Snapping ​

  • Straight line endpoint snapping: Enable/disable snapping for line ends.
  • Snapping distance: Set the radius for endpoint snapping (5-50 pixels).

Shape Recognition ​

  • Enable shape recognition: Turn on automatic shape recognition.
  • Recognize rectangle: Recognize and optimize drawn rectangles and squares.
  • Recognize triangle: Recognize and optimize drawn triangles.
  • Recognize circle: Recognize and optimize drawn circles and ellipses.
  • Rectangle pressure: Apply pressure sensitivity effects inside recognized rectangles.
  • Triangle pressure: Apply pressure sensitivity effects inside recognized triangles.

Personalization ​

Toolbar Settings ​

  • Floating toolbar icons: Select different icon styles.
  • Toolbar scale: Adjust the size of the toolbar (0.5x to 1.25x).
  • Toolbar opacity: Adjust the transparency of the toolbar (0.3 to 1.0).
  • PPT mode opacity: Specific toolbar transparency when PowerPoint is active.

Interface Options ​

  • Show nib mode button: Toggle the visibility of the nib mode switch in the color palette.
  • Whiteboard UI scale: Enable 80% UI scaling under whiteboard mode.
  • Show date and time: Show the current time in whiteboard mode.
  • Quick panel: Enable the quick panel when the toolbar is docked.
  • Dock button icon: Choose between arrow or pen-shaped dock icons.

Advanced Settings ​

Touch Settings ​

  • Touch multiplier: Fine-tune touch sensitivity.
  • Nib mode border width: Set the boundary width for stylus detection.
  • Finger mode border width: Set the boundary width for finger touch detection.

System Integration ​

  • Full screen helper: Improve drawing experiences in full-screen applications.
  • Edge gestures: Enable or disable Windows edge gestures.
  • Force full screen: Run the application in forced full-screen mode.
  • DPI change detection: Detect and adapt to display DPI changes.
  • Resolution change detection: Monitor and adapt to screen resolution changes.

Logs ​

  • Enable logging: Record application activity logs for troubleshooting.
  • Confirm close: Show a confirmation dialog when exiting the application.

Automation Settings ​

Software Detection ​

Enable automatic detection of specific software to optimize ICC-CE behavior:

  • EasiNote, EasiCamera
  • Various whiteboard software (Seewo, Haixin, Nano, etc.)
  • PowerPoint Slideshows
  • Microsoft Whiteboard
  • Other common educational software

Auto Save ​

  • Screenshot save location: Set the storage path for screenshots.
  • Date folders: Organize saved files inside folders named by date.
  • Save ink on screenshot: Save raw ink strokes along with the screenshot.
  • Save ink on clear: Save canvas content before clearing it.
  • Auto delete files: Automatically clean up historical files.
  • Retention days: Set the maximum lifetime for auto-saved files.

PowerPoint Settings ​

Button Settings ​

  • Show PPT buttons: Display control buttons in slideshow mode.
  • Page numbers clickable: Allow switching slides by clicking page numbers.
  • Button position: Adjust the position of the buttons on the left or right side.
  • Button style: Customize button transparency, background, and display options.

Behavior Settings ​

  • Show canvas on new slide: Automatically display the canvas when switching slides.
  • Save slide ink: Automatically save annotations drawn on slides.
  • Page notification: Display notifications when changing slides.
  • Gesture control: Enable gesture controls during slideshows.
