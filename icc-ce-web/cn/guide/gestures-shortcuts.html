手势与快捷操作 ​

字数: 0 字    时长: 0 分钟

触控手势 ​

ICC-CE 的手势系统可以在设置中整体开关，也可以逐项启用。

手势效果
单指拖动书写（画笔模式下）
双指捏合 / 张开缩放画布
双指拖动平移画布
双指旋转旋转画布（需在设置中启用）
双指点击撤销
三指点击重做
多指长按呼出快捷菜单

手势不生效

先确认设备真的支持多点触控：设备管理器 → 人体学输入设备中应能看到「HID 兼容触摸屏」。 部分老旧一体机的触摸驱动会把双指手势直接吞掉，需要更新为厂商官方驱动。

防误触 ​

书写时手掌搭在屏幕上容易产生杂线。ICC-CE 提供掌压屏蔽功能：

  • 开启后会自动忽略接触面积过大的触点
  • 可调整判定阈值，屏幕越大阈值可设得越宽松
  • 使用主动式电容笔的设备可以直接开启「仅笔书写」，彻底忽略手指输入

笔身按键 ​

支持的数位笔通常有一到两个侧键，可在设置中分别映射为橡皮擦、选择、撤销等功能。 不少设备把笔尾直接做成橡皮，翻转笔身即可擦除。

常用快捷操作 ​

操作说明
撤销 / 重做工具栏按钮或双指 / 三指点击
清空画布工具栏清空按钮，会进入撤销栈，可以撤销回来
截屏把当前屏幕连同墨迹保存为图片
切换透明 / 白板模式工具栏模式按钮
收起工具栏点击工具栏折叠按钮，书写不受影响
退出工具栏退出按钮，会触发一次自动保存

清空与撤销

清空画布是可撤销的，但退出程序后撤销栈不保留。重要内容请先截屏或等待自动保存完成。

与 PowerPoint 放映配合 ​

放映时工具栏会额外出现翻页按钮，翻页会自动切换对应页的墨迹。 翻页动作本身不进入撤销栈，详见PPT 联动指南。
