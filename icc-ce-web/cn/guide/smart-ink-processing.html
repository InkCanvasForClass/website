智能笔迹处理 ​

字数: 0 字    时长: 0 分钟

ICC-CE 提供了强大的墨迹渲染与手绘辅助功能，能够在绘图和书写时自动对笔迹进行平滑、拉直与形状优化。

智能绘图辅助 ​

线条拉直功能 ​

当绘制接近直线的笔画时，ICC-CE 可以自动识别并将其转换为完美直线。您可以通过设置调整灵敏度和阈值：

参数说明可调范围
灵敏度设置控制系统对线条直线度的判断标准0.05 - 2.0
长度阈值只有超过设定长度的线条才会被考虑自动拉直视像素数值调节

使用建议

在绘制几何图形或标注对齐线条时，适当提高灵敏度可以获得更精准的直线效果。

形状识别 ​

自动识别并优化手绘图形，使其转换为标准几何形状：

  • 矩形和正方形
  • 三角形
  • 圆形和椭圆

端点吸附 ​

绘制线条时，线条端点会自动吸附到附近的其他端点，便于快速创建封闭或连接良好的复杂几何图形。

多样化绘图工具 ​

笔与荧光笔 ​

  • 粗细与透明度：支持动态调节画笔粗细与不透明度
  • 预设颜色：内置丰富的调色板与快捷颜色选择
  • 压感支持：在支持压感的手绘板或主动式电容笔设备上，自动响应书写力度

触摸模式与优化 ​

模式特性
指尖绘图针对普通触摸屏优化，支持使用手指直接绘制
笔尖模式专为手写笔设计的精确绘图模式，防误触体验更佳
模拟压感在不支持硬件压感的设备上，根据书写速度动态模拟压感粗细变化

橡皮擦功能 ​

  • 点擦模式：精确擦除笔画的局部重叠部分
  • 笔画擦除：点击笔画即可一次性擦除整条笔迹
  • 形状与大小：支持调整橡皮擦作用域的大小和覆盖形状
