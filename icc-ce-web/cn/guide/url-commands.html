URL 命令调用 ​

字数: 0 字    时长: 0 分钟

ICC-CE 支持通过 icc:// 开头的网址来控制软件。您可以把常用操作做成桌面快捷方式，或者交给一体机的中控软件、班牌系统去调用。

比较典型的用法：

  • 上课前用一条命令切换到您习惯的配置方案
  • 下课时一键清空墨迹并收纳工具栏
  • 让中控面板上的实体按钮直接切换画笔和橡皮

先打开开关 ​

这个功能默认是关闭的，需要先启用：

  1. 打开设置 → 启动
  2. 找到「外部协议调用 (icc://)」，说明文字是「通过 icc:// 协议从外部控制软件」
  3. 把开关打开

没打开开关时命令会被忽略

软件不会弹任何提示，命令就是没反应。如果您试了半天没效果，先回来确认这个开关是开着的。

移动过软件文件夹，要关掉开关再打开

ICC-CE 是绿色软件。如果您把整个文件夹移动、改名或换了盘，命令就会失效——但开关仍然显示为开启，界面上看不出任何异常。

原因是记录的启动位置还指向旧地址。解决办法很简单：把「外部协议调用」开关关掉，再重新打开，位置就更新了。

另外这个设置只对当前 Windows 账户生效。教室电脑如果有多个账户，每个账户都要各自打开一次。

怎么用 ​

直接运行 ​

按 Win + R，输入命令回车，比如：

icc://fold
1

浏览器地址栏里输入也可以，会提示您确认打开 ICC-CE。

做成桌面快捷方式 ​

  1. 桌面右键 → 新建 → 快捷方式
  2. 位置填命令，例如 icc://clear
  3. 起个名字，比如「清空墨迹」

双击就能用。也可以右键快捷方式 → 属性 → 快捷键，给它配一个组合键。

写成批处理 ​

新建一个 .bat 文件，几条命令连起来：

bat
start icc://config-profile/switch?name=上课
timeout /t 1
start icc://unfold
1
2
3

连续命令之间留点时间

每条命令都会去唤起软件，连着发太快可能有的没被处理。像上面那样用 timeout /t 1 隔开一秒比较稳妥。

给中控软件用 ​

大部分一体机的中控软件都支持"执行自定义命令"或"打开链接"，把 icc:// 命令填进去就行。软件没启动时会自动启动，已经在运行就直接执行。

命令地址一览 ​

工具栏 ​

地址效果
icc://fold收纳工具栏
icc://unfold展开工具栏
icc://toggle收纳与展开来回切换
icc://thoroughhideon开启「收纳时彻底隐藏」
icc://thoroughhideoff关闭「收纳时彻底隐藏」
icc://thoroughhidetoggle切换该选项

thoroughhide 这三条会改动并保存设置，跟您在设置里手动改是一样的效果。

画笔与工具 ​

地址效果
icc://tool/pen切到画笔
icc://tool/cursor切到光标（鼠标模式）
icc://tool/eraser切到面积橡皮
icc://tool/eraserbystrokes切到笔画橡皮
icc://tool/select切到套索选择

墨迹 ​

地址效果
icc://clear清空当前墨迹
icc://clearall清空墨迹，并且不能再撤销
icc://undo撤销
icc://redo重做

clearall 清掉的东西找不回来

icc://clear 清空后还能用 icc://undo 撤销回来。icc://clearall 会连撤销记录一起清掉，没法恢复。做快捷方式时留意别弄混。

白板翻页 ​

地址效果
icc://nextpage下一页
icc://previouspage上一页
icc://newpage新建一页
icc://deletepage删除当前页

功能 ​

地址效果
icc://whiteboard打开/关闭白板
icc://rand随机点名
icc://randone抽一个人
icc://timer倒计时
icc://screenshot截图并插入画布

配置方案 ​

如果您建了多个配置方案（比如「语文课」「数学课」），可以直接切换：

icc://config-profile/switch?name=方案名
1

方案名要写得完全一致

大小写、空格都得跟您建的方案名一模一样，写错了不会有提示，只是不生效。名字里有空格或中文一般没问题，直接写就行。

打开设置页 ​

icc://settings
1

也可以直接跳到某一页，例如打开画布设置：

icc://settings/CanvasPage
1

重启与退出 ​

地址效果
icc://restart重启软件
icc://exit退出软件
icc://restart/admin以管理员身份重启
icc://restart/normal以普通身份重启

这几条命令 3 秒内只执行一次

防止中控面板的按钮被连按导致反复重启。3 秒内重复的会被忽略，这是正常的。

墨迹冻结 ​

配合墨迹冻结功能使用：

地址效果
icc://freeze冻结当前页
icc://unfreeze解冻当前页
icc://freeze/start课程开始
icc://freeze/end课程结束
icc://freeze/cancel取消

想指定某一页，加上 ?page=（范围 0 到 100）：

icc://freeze?page=3
1

用 URL 解冻会跳过密码

如果您给冻结的页面设了密码，icc://unfreeze 不会要求输入密码就直接解冻。

这也是为什么「外部协议调用」默认关闭。如果您依赖冻结密码来防止学生改动内容，就不要打开这个开关，或者至少不要把解冻命令做成桌面上的快捷方式。

命令没反应？ ​

按顺序检查：

  1. 开关是否打开 — 设置 → 启动 → 外部协议调用 (icc://)，这是最常见的原因
  2. 软件文件夹是否移动过 — 移动后需要重新打开一次开关
  3. 地址是否拼错 — 命令不区分大小写，icc://Fold 和 icc://fold 都行，但拼错字就不认了
  4. 配置方案名是否对得上 — 方案名区分大小写，要完全一致
  5. 是不是 3 秒内重复调用了重启/退出 — 这是有意的限制

都排除了还不行的话，可以到软件目录下的 Logs 文件夹里找最新的日志文件，搜索 URI 就能看到软件收到了什么命令、为什么没执行。反馈问题时附上这段日志会快很多。
