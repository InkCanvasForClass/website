安装与更新通道 ​

字数: 0 字    时长: 0 分钟

正在施工

本文档的这篇文章正在持续更新中，部分内容可能尚未完成或存在变更。

系统要求 ​

项目要求
操作系统Windows 10 版本 1809（build 17763）及以上、Windows 11
运行时.NET 6 桌面运行时（net6.0-windows10.0.19041.0）
内存建议 4GB 以上
显卡支持 Direct3D 11 的显卡可启用硬件加速墨迹渲染
输入设备触摸屏 / 数位板 / 鼠标均可，触控设备体验最佳

关于 .NET 版本

主程序运行在 .NET 6 上，不是 .NET Framework 4.x。安装版会在需要时提示安装运行时； 绿色版若无法启动，多半是缺少 .NET 6 桌面运行时，请到微软官网下载 “.NET Desktop Runtime 6.x” 的 x64 或 x86 版本。

但是，手写识别所依赖的 IACore 组件只有 32 位版本，程序会额外启动一个 .NET Framework 4.7.2 的辅助进程来调用它。 这部分由安装包处理，通常无需手动干预。

安装版还是绿色版 ​

发布页同时提供两种形态，功能完全一致：

安装版（.exe）绿色版（.zip）
安装方式运行安装向导解压到任意目录
开始菜单/桌面快捷方式自动创建需手动创建
卸载控制面板卸载直接删除文件夹
写入系统是（安装目录、注册表卸载项）否
适用场景个人电脑、长期使用U 盘便携、机房批量部署、多版本并存

推荐

班级一体机等长期使用的设备建议用安装版；需要在多台机器间携带、或想同时保留多个版本时用绿色版。

位数选择（32 位 / 64 位） ​

  • 现代设备一律选 64 位（x64）
  • 仅在系统为 32 位、或需要与 32 位 Office 深度联动时选 32 位（x86）

不确定时按 Win + Pause 查看“系统类型”。

四个更新通道 ​

下载页的通道切换对应四类不同的构建来源：

通道说明
Beta（推荐）更新最快、修复最及时，日常使用首选
Preview稳定度更高，想尝鲜又偏好稳定时选
正式版稳定性优先，适合正式环境
Nightly未经测试的调试构建，仅供测试用，更新到下一个Nightly版本需要自行下载更新替换

Nightly 构建

Nightly 是 CI 从 net6 分支最新提交自动产出的 Debug 版本，没有经过任何测试，可能包含严重缺陷、崩溃或数据丢失风险。 请勿在正式课堂环境使用。 下载页会强制你阅读风险说明并勾选确认后才允许下载。

升级 ​

ICC-CE 内置在线更新检查，在设置中可配置检查频率与更新通道。手动升级时：

  • 安装版：直接运行新版本安装包覆盖安装即可，配置与墨迹保留
  • 绿色版：解压新版本到旧版本程序目录覆盖即可

具体的数据目录位置见配置文件与数据目录。

跨通道切换

从 Beta 回退到正式版时，可能出现新版本写入的配置项无法被旧版本识别的情况。 如遇异常，请备份后删除配置文件让程序重新生成。

卸载 ​

  • 安装版：设置 → 应用 → 已安装的应用 → InkCanvasForClass CE → 卸载
  • 绿色版：直接删除整个文件夹

卸载不会自动清除用户配置与墨迹存档，需要彻底清理时请手动删除数据目录。
