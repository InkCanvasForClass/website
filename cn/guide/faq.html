已知问题

本文档描述的此功能存在已知的 Bug 或限制，可能在某些情况下无法正常工作。

安装与运行 ​

程序无法启动，提示缺少 .NET 运行时 ​

ICC-CE 需要 .NET 6 桌面运行时。请到微软官网搜索 ".NET Desktop Runtime 6.x" 下载对应架构（x64 / x86）的版本。安装版会在需要时自动提示下载。

绿色版无法启动 ​

多半是缺少 .NET 6 桌面运行时，请按上述方式安装。如果确认已安装，请检查下载的压缩包是否完整，尝试重新解压。

安装版提示"无法安装" ​

可能是系统版本过低，请确认 Windows 10 版本 ≥ 1809（build 17763）。也可能是杀毒软件误报，请将 ICC-CE 加入白名单。

运行时提示"已停止工作" ​

  1. 检查系统版本是否满足要求
  2. 尝试以管理员身份运行
  3. 查看日志文件（%AppData%\InkCanvasForClass CE\Logs\）了解详细错误信息
  4. 如持续崩溃，请提交 GitHub Issue 并附上日志

PPT 联动 ​

进入 PPT 放映后没有自动进入标注模式 ​

  1. 确认 PowerPoint 已激活，不是保护模式/只读模式
  2. 检查 ICC-CE 设置中 PPT 联动已开启（默认开启）
  3. 检查 PowerPoint 是否以管理员身份运行，而 ICC-CE 未提权，两者权限不一致会导致无法联动
  4. 尝试切换联动模式（COM / ROT / Agent）

标注的墨迹保存后找不到 ​

默认保存位置：%AppData%\InkCanvasForClass CE\Saves\。可在设置中自定义保存路径，或开启保存时自动重命名避免覆盖。

翻页时墨迹丢失 ​

请确认设置中"新幻灯片显示画布"已开启，且"退出时隐藏墨迹"已开启。翻回已标注页面时，墨迹应该自动恢复。

与 WPS 联动不工作 ​

开启设置中的"WPS 支持"选项，并确保 WPS 不是以管理员身份运行。

墨迹与手写 ​

笔迹延迟/卡顿 ​

  1. 关闭硬件加速（设置 → 画板与墨迹 → 高级笔触 → 硬件加速）
  2. 降低墨迹平滑质量（设置 → 画板与墨迹 → 高级笔触 → 墨迹平滑质量）
  3. 关闭异步墨迹平滑
  4. 检查显卡驱动是否为最新版本

笔迹不流畅/有锯齿 ​

  1. 确保高级贝塞尔平滑已开启
  2. 检查笔锋模式是否设置为"关闭"，关闭笔锋可让笔迹更均匀
  3. 调整笔迹平滑质量为"高质量"

手势不生效 ​

  1. 确保设置中手势总开关已开启
  2. 检查是否在正确的模式下使用了手势（屏幕批注模式手势和白板模式手势独立配置）
  3. 检查是否启用了"仅笔书写"模式，此模式下手指输入会被忽略
  4. 检查是否被其他软件（如 Windows Ink 工作区）拦截

形状识别不准确 ​

  1. 确认"启用形状识别"已开启
  2. 确认具体形状（矩形/三角形/圆形）的识别开关已开启
  3. 调整直线拉直灵敏度，尝试降低灵敏度值以提高识别精度
  4. 书写时尽量一笔完成，避免断笔

性能与兼容 ​

程序占用 CPU/内存过高 ​

  1. 关闭硬件加速
  2. 降低墨迹平滑质量
  3. 关闭异步墨迹平滑
  4. 减少日志级别（如从"调试"改为"信息"）
  5. 关闭悬浮窗拦截功能（该功能会增加性能开销）
  6. 检查是否有其他进程与 ICC-CE 冲突

与某些软件冲突 ​

ICC-CE 的悬浮窗拦截功能可屏蔽希沃、鸿合等教学软件的浮动窗口。如果遇到其他软件冲突，可尝试关闭该功能或调整相关设置。

多显示器支持 ​

ICC-CE 支持多显示器环境，可在设置中启用多显示器相关选项。如果遇到画布显示异常，尝试开启"多显示器画布修复"。

文件与数据 ​

如何备份配置和数据 ​

备份 %AppData%\InkCanvasForClass CE\ 整个目录即可。重装系统或迁移到新电脑时，将备份数据复制到相同路径。

如何彻底卸载 ​

  • 安装版：设置 → 应用 → 已安装的应用 → InkCanvasForClass CE → 卸载
  • 绿色版：直接删除整个文件夹

卸载不会自动清除用户配置与墨迹存档，需要彻底清理时请手动删除 %AppData%\InkCanvasForClass CE\ 目录。

如何恢复默认设置 ​

删除 %AppData%\InkCanvasForClass CE\Configs\Settings.json，程序将在下次启动时生成默认配置。建议先备份原文件。

更新相关 ​

如何切换更新通道 ​

在设置中修改"更新通道"即可。Beta 通道更新最快，正式版最稳定。

跨通道切换后出现异常 ​

从 Beta 回退到正式版时，可能出现新版本写入的配置项无法被旧版本识别的情况。如遇异常，请备份后删除配置文件让程序重新生成。

更新失败 ​

  1. 检查网络连接
  2. 尝试手动下载最新版本安装包
  3. 检查更新通道设置是否正确
  4. 查看日志文件了解详细错误信息

如何获取帮助 ​

  • GitHub Issues：访问项目仓库提交问题
  • 日志文件：%AppData%\InkCanvasForClass CE\Logs\，提交问题时请附上日志
  • 配置导出：如需帮助排查问题，可导出设置分享给开发者
