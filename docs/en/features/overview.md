# Features Overview

## Smart Ink Processing

### Straight Line Correction

When drawing strokes close to a straight line, ICC-CE can automatically identify and convert them into perfect straight lines. You can adjust the sensitivity and threshold in the settings:

- **Sensitivity setting**: Controls the threshold for line straightness detection, ranging from 0.05 to 2.0.
- **Length threshold**: Only lines exceeding the set length will be considered for straightening.

### Shape Recognition

Automatically recognizes and optimizes hand-drawn shapes, including:

- Rectangles and Squares
- Triangles
- Circles and Ellipses

### Endpoint Snapping

When drawing lines, endpoints will automatically snap to other endpoints nearby, making it easier to create well-connected geometric drawings.

## Diverse Drawing Tools

### Pen and Highlighter

- Adjustable brush thickness and opacity.
- A rich selection of preset colors.
- Pen pressure sensitivity support (for devices supporting pressure levels).

### Touch Modes

- Finger Drawing: Draw directly using touch screens.
- Nib Mode: A high-precision drawing mode specifically designed for active styluses.
- Simulated Pressure: Simulates pressure effects on devices that do not support hardware pressure sensitivity.

### Eraser

- Point Erasing: Precisely erase parts of ink strokes.
- Stroke Erasing: Erase the entire stroke at once.
- Adjustable eraser size and shape.

## PowerPoint Integration

### Presentation Enhancements

- Annotate directly in slideshow/presentation mode.
- Customizable control buttons for easy slideshow navigation.
- Save slideshow screenshots containing annotations.

### Gesture Control

- Control slide switching using hand gestures.
- Zoom and pan annotated contents.
- Rotate and rearrange drawn elements.

## Multi-touch Support

- Two-finger Zoom: Zoom in or out of the drawing canvas.
- Rotate Gesture: Rotate the selected elements.
- Panning Operation: Move around the drawing canvas.

## Automation Features

### Auto Detection

- Detect common whiteboard and teaching applications.
- Adaptive interface behavior to avoid blocking other apps.
- Optimize performance under different software environments.

### Auto Save

- Save drawing contents at regular intervals.
- Automatically back up the canvas before clearing it.
- Organize screenshots and ink files inside date folders.

## UI Customization

- Adjust toolbar opacity and scale.
- Multiple icon style options.
- Whiteboard mode UI scaling.
- Quick panel and side-docking mode.
