## Three Working Modes

ICC-CE provides three core working modes, switchable via the mode button on the toolbar:

### Screen Annotation Mode (Default)

Overlays a transparent canvas on top of the screen, allowing you to write and annotate over any software interface.

- Ideal for real-time annotations on PPT, PDF, browser, video players, etc.
- Toolbar floats on the screen edge for quick tool switching
- Supports ink saving, screenshots, undo/redo, and more

### Whiteboard Mode

Full-screen solid background, functioning as an electronic whiteboard.

- Full-screen writing space, perfect for classroom board writing
- Supports image insertion, background grid
- Toolbar is positioned on both sides of the screen, providing more writing tools
- Supports extended canvas for unlimited writing space

### Mouse Mode

Disables ink drawing, allowing the mouse to pass through to the underlying application for normal operation.

- Can be quickly toggled with Screen Annotation Mode
- Suitable for scenarios where you frequently switch between writing and operating applications

## Interface & Toolbar

### Toolbar Layout

The toolbar floats by default on the right edge of the screen, mainly containing:

| Area | Function |
| --- | --- |
| Pen Tools | Pen, highlighter, laser pointer, eraser |
| Color Selection | Quick color palette, custom colors |
| Width Adjustment | Stroke thickness slider |
| Mode Switch | Screen Annotation / Whiteboard / Mouse Mode |
| Toolbox | Settings, screenshot, clear screen, save, undo/redo |
| PPT Control | Page navigation, jump (appears automatically during slideshow) |

### Toolbar States

- **Expanded**: Fully displays all tool buttons
- **Collapsed**: Shrinks to a thin strip on the screen edge; hover or click to expand
- **Mini Bar**: Automatically shrinks to a compact rounded mini toolbar after a period of inactivity (requires enabling in settings)

### Quick Panel

In collapsed mode, a quick panel appears at the bottom of the screen, providing fast access to commonly used tools.

## Daily Usage Scenarios

### Classroom Teaching

1. Open PPT and start slideshow; ICC-CE automatically enters annotation mode
2. Use the pen to write key points on slides
3. Use the highlighter to emphasize important content
4. Ink is automatically saved when switching slides and restored when returning
5. Export annotated screenshots or time capsules after class

### Online Teaching

1. Use Screen Annotation Mode to annotate courseware or browser content in real-time
2. Combine with Whiteboard Mode for board writing explanations
3. Use the laser pointer to guide attention
4. Take screenshots to share lecture content with students

### Meeting Presentations

1. Annotate presentation documents in real-time
2. Use shape recognition to quickly draw standard graphics
3. Use two-finger zoom/pan to view details
4. Save ink files and screenshots for archiving after the meeting

### Daily Office Work

1. Screenshot annotation: Capture screen content and add annotations
2. Document annotation: Write comments on PDFs or documents
3. Scratchpad: Quickly record ideas and sketches
