# Advanced Tips

Master these advanced techniques to unleash the full potential of ICC-CE:

## Shape Drawing Tips

### Perfect Straight Lines

1. Enable straight line correction (Settings → Canvas → Straight line correction)
2. Adjust sensitivity to match your drawing style:

   - Low Sensitivity (0.05-0.3): Requires lines to be very close to straight.
   - Medium Sensitivity (0.3-1.0): Suitable for most users.
   - High Sensitivity (1.0-2.0): Even slightly curved lines will be corrected as straight.

3. Maintain a steady speed when drawing; avoid drawing too fast or too slow.

### Precise Shapes

Use shape recognition to create precise figures:

1. Enable shape recognition (Settings → Shape Recognition)
2. Choose the shape types to recognize (Rectangle, Triangle, Circle, etc.)
3. Draw close to the target shape, and the system will automatically optimize it.

::: tip Tip
Try closing your strokes for the best recognition results. For example, when drawing a rectangle, ensure you end near the starting point.
:::

### Connecting Figures

Endpoint snapping helps create well-connected complex figures:

1. Enable endpoint snapping (Settings → Canvas → Straight line endpoint snapping)
2. Adjust snap distance to control the snapping range.
3. Draw new lines starting or ending close to the endpoints of existing lines.

## Touch Gestures

ICC-CE supports multi-touch gestures to enhance interaction:

| Gesture | Action | Applicable Mode |
| --------- | ------------------- | -------- |
| Two-finger pinch | Zoom drawing area | All modes |
| Two-finger rotate | Rotate selected content | Selection mode |
| Two-finger drag | Pan drawing area | All modes |
| Left/Right swipe | Next/Prev page (PowerPoint) | Presentation mode |

### Customizing Gestures

In Settings → Gestures, you can:

- Enable/Disable specific gestures
- Adjust gesture sensitivity
- Configure gesture behaviors under specific modes

## PowerPoint Enhancement Tips

### Presentation Navigation Optimization

1. Use customizable navigation buttons to quickly switch slides.
2. Adjust button position and transparency to avoid blocking content.
3. Enable slide preview to see upcoming content.

### Efficient Annotation

1. Use preset colors to quickly switch and highlight different concepts.
2. Utilize Whiteboard mode to explain complex concepts, then return to slides.
3. Use the "Clear all annotations" function to quickly reset the current slide.

## Automated Workflows

### Smart Software Detection

ICC-CE can detect and adapt to other educational software:

1. Enable relevant options in Settings → Automation.
2. When specific software is detected, ICC-CE will automatically adjust its behavior.
3. Set auto-docking conditions to avoid interface conflicts.

### Content Management

Configure auto-save strategies:

1. Configure auto-save location (Settings → Automation → Auto-save location).
2. Set auto-cleanup options to manage historical files.
3. Enable date folders to organize screenshots and ink files.

## Performance Optimization

If you encounter performance issues during use:

1. Adjust canvas clearing strategies to reduce memory usage.
2. Enable UI scaling on high-resolution screens.
3. Use non-transparent mode to boost drawing performance.
4. Regularly clean up auto-saved folders.
