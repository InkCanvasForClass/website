# Getting Started

<UnderConstruction />

ICC-CE (Ink Canvas for Class Community Edition) is a free and open-source screen annotation and whiteboard software, designed for classroom teaching and presentation scenarios. It allows you to write and annotate in real-time over any software interface (PPT, PDF, browser, video, etc.), or switch to full-screen whiteboard mode for board writing.

## Quick Install

1. Visit the [Download Center](/en/download) to get the latest version
2. Choose **Installer (.exe)** to run the setup wizard, or download **Portable (.zip)** to extract to any directory
3. Launch the program, and the toolbar will float on the screen edge

> For detailed installation instructions, see [Installation & Update Channels](/en/guide/installation).

## One Minute Quick Start

1. **Launch the program**: Double-click the desktop shortcut or run the main executable
2. **Start writing**: Use pen/finger to write directly over any software interface
3. **Switch tools**: Click the pen, highlighter, laser pointer, or eraser buttons on the toolbar
4. **Change colors**: Click the color button to select stroke color
5. **Clear screen**: Click the clear button to remove all ink
6. **Exit**: Right-click the tray icon → Exit

> For a complete usage guide, see [Instruction Manual](/en/guide/instruction-manual).
