# Getting Started

## System Requirements

- <badge type="tip" text="OS" /> Windows 10/11
- <badge type="tip" text="Memory" /> At least 4GB RAM
- <badge type="info" text="Hardware" /> Touch-input supported device (Recommended, but not required)
- <badge type="warning" text=".NET" /> Microsoft .NET Framework 4.7.2 or higher

## Installation Steps

1. Download the latest version
2. Extract the downloaded zip file to a folder of your choice
3. Run `InkCanvasForClass.exe` to launch the application
4. On the first run, the software will prompt you to complete the initial setup

## Basic Operations

### Launching the App

Double-click `InkCanvasForClass.exe` to launch the app. Once started, you will see a floating toolbar to control drawing tools and settings.

### Floating Toolbar

![Floating Toolbar](https://github.com/user-attachments/assets/f47e80a8-05b8-44ab-8c70-6771e97375ea)

The floating toolbar provides the following functions:

- Pen Tool: For free-hand drawing
- Highlighter: For semi-transparent annotations
- Eraser: For erasing drawings
- Color Palette: Change pen and highlighter colors
- Settings: Access application configuration
- Fold/Unfold: Minimize or expand the toolbar

### Drawing Modes

ICC-CE supports two main drawing modes:

1. **Transparent Mode**: Draw over any application or desktop, ideal for screen annotation
2. **Whiteboard Mode**: Provides a dedicated drawing space, perfect for complex drawings or math calculations

Switch modes by clicking the corresponding icon on the toolbar.

### Saving and Sharing

You can save your work at any time via:

- Screenshot function: Saves current view as an image
- Export drawings: Save to various formats
- Auto-save feature: Ensures you never lose important content

## Integration with PowerPoint

ICC-CE integrates seamlessly with PowerPoint to add real-time drawing capabilities to your presentations:

1. Start PowerPoint and open your presentation
2. Enter Slideshow mode
3. ICC-CE will automatically detect PowerPoint and enable special integration features
4. Draw using the toolbar, and annotations will be displayed directly on the slides
