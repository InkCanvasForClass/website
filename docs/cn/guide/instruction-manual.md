## 三种工作模式

ICC-CE 提供三种核心工作模式，可通过工具栏上的模式按钮切换：

### 屏幕批注模式（默认）

在屏幕上方覆盖一层透明画布，可在任何软件界面上方书写标注。

- 适合在 PPT、PDF、浏览器、视频播放器等上方实时标注
- 工具栏浮动在屏幕边缘，方便快速切换工具
- 支持墨迹保存、截图、撤销/重做等操作

### 白板模式

全屏纯色背景，充当电子白板使用。

- 全屏书写空间，适合课堂板书
- 支持插入图片、背景网格
- 工具栏位于屏幕两侧，提供更多书写工具
- 支持扩展画布，可无限延伸书写空间

### 鼠标模式

关闭墨迹绘制，鼠标穿透到下层应用正常操作。

- 可与屏幕批注模式快速切换
- 适合在书写和操作应用之间频繁切换的场景

## 界面与工具栏

### 工具栏布局

工具栏默认浮动在屏幕右侧边缘，主要包含：

| 区域 | 功能 |
| --- | --- |
| 画笔工具 | 笔、荧光笔、激光笔、橡皮擦 |
| 颜色选择 | 快速调色盘、自定义颜色 |
| 宽度调节 | 笔触粗细滑块 |
| 模式切换 | 屏幕批注 / 白板 / 鼠标模式 |
| 工具箱 | 设置、截图、清屏、保存、撤销/重做 |
| PPT 控制 | 翻页、跳转（放映时自动出现） |

### 工具栏状态

- **展开状态**：完整显示所有工具按钮
- **收纳状态**：缩为屏幕边缘细条，鼠标悬停或点击展开
- **迷你栏**：闲置一段时间后自动缩为紧凑圆角迷你工具栏（需在设置中开启）

### 快捷面板

收纳模式下，屏幕底部会显示快捷面板，提供常用工具的快速访问。

## 日常使用场景

### 课堂授课

1. 打开 PPT 开始放映，ICC-CE 自动进入标注模式
2. 使用笔在幻灯片上书写重点
3. 使用荧光笔高亮关键内容
4. 翻页时墨迹自动保存，翻回自动恢复
5. 课后可导出带有标注的截图或时间胶囊

### 在线教学

1. 使用屏幕批注模式在课件或浏览器上实时标注
2. 结合白板模式进行板书讲解
3. 使用激光笔引导注意力
4. 截图保存讲课内容发给学生

### 会议演示

1. 在演示文档上方实时标注
2. 使用形状识别快速绘制标准图形
3. 使用双指缩放/平移查看细节
4. 会后保存墨迹文件和截图归档

### 日常办公

1. 截图标注：截取屏幕内容后添加标注
2. 文档批注：在 PDF 或文档上书写批注
3. 草稿本：快速记录想法和示意图
