# 手势与快捷键

<UnderConstruction />

## 触控手势

ICC-CE 支持触控设备上的多点手势，分别在屏幕批注模式和白板模式各自独立配置。

### 屏幕批注模式手势

| 手势 | 功能 | 默认状态 |
| --- | --- | --- |
| 双指缩放 | 两根手指缩放画布内容 | 开启 |
| 双指平移 | 两根手指移动画布视口 | 开启 |
| 双指旋转 | 两根手指旋转画布 | 关闭 |
| 选区双指旋转 | 选中墨迹后双指旋转选区 | 关闭 |
| 双指点击撤销 | 双指点击屏幕撤销上一步 | 关闭 |
| 三指点击重做 | 三指点击屏幕重做上一步 | 关闭 |

### 白板模式手势

| 手势 | 功能 | 默认状态 |
| --- | --- | --- |
| 白板双指缩放 | 白板模式下双指缩放画布 | 开启 |
| 白板双指平移 | 白板模式下双指移动画布 | 开启 |
| 白板双指旋转 | 白板模式下双指旋转画布 | 关闭 |

### 掌压屏蔽

| 设置项 | 说明 |
| --- | --- |
| 掌压屏蔽 | 自动忽略接触面积过大的触点，防止手掌误触 |
| 仅笔书写 | 彻底忽略手指输入，仅接受主动式电容笔 |

## 触碰操作

| 操作 | 功能 |
| --- | --- |
| 点击工具栏按钮 | 切换工具/触发功能 |
| 长按 | 呼出更多选项（如颜色选择、宽度选择） |
| 拖拽 | 移动工具栏位置 |
| 滑动 | 白板模式下平移画布 |

## 快捷键

### 全局快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Win + Shift + O` | 显示/隐藏工具栏 |
| `Win + Shift + 1-9` | 切换画笔预设 |
| `Win + Shift + C` | 切换至颜色选择 |
| `Win + Shift + E` | 切换至橡皮擦 |
| `Win + Shift + L` | 切换至激光笔 |
| `Win + Shift + P` | 切换至指针模式 |
| `Win + Shift + S` | 截屏 |
| `Win + Shift + U` | 撤销 |
| `Win + Shift + R` | 重做 |
| `Win + Shift + A` | 清除所有墨迹 |
| `Win + Shift + +` | 放大 |
| `Win + Shift + -` | 缩小 |
| `Win + Shift + 0` | 重置缩放 |

### 鼠标模式快捷键

鼠标模式下全局快捷键默认不响应，需在设置中手动开启"鼠标模式启用全局快捷键"。

### 自定义快捷键

部分快捷键可在设置中自定义，包括：
- 切换笔/荧光笔/激光笔
- 切换颜色
- 切换宽度
- 撤销/重做
- 清屏
- 截图
- 显示/隐藏工具栏
