# 安装与更新通道

<KnownBugs />

## 系统要求

在开始之前，请确认你的设备满足以下条件：

| 项目 | 要求 |
| --- | --- |
| **操作系统** | Windows 10 版本 1809（build 17763）及以上，或 Windows 11 |
| **运行时** | .NET 6 桌面运行时（x64 或 x86） |
| **内存** | 建议 4 GB 以上 |
| **显卡** | 支持 Direct3D 11 的显卡可启用硬件加速墨迹渲染 |
| **输入设备** | 鼠标可用；触摸屏 / 数位板 / 主动式电容笔体验更佳 |

::: tip 如何查看系统版本？
按 <kbd>Win</kbd> + <kbd>Pause</kbd> 即可打开系统信息，查看 Windows 版本和系统类型（64 位 / 32 位）。
:::

::: warning 关于 .NET 运行时
ICC-CE 运行在 .NET 6 上，**不是** .NET Framework。安装版会在需要时自动提示下载运行时；绿色版若无法启动，多半是缺少 .NET 6 桌面运行时，请到微软官网搜索 ".NET Desktop Runtime 6.x" 下载安装对应架构（x64 / x86）的版本。
:::

## 获取安装包

访问 [下载中心](/cn/download) 选择你需要的版本。页面会自动检测最优下载线路。

### 四个更新通道的区别

| 通道 | 说明 | 适用场景 |
| --- | --- | --- |
| **Beta（推荐）** | 更新最快、修复最及时，经过 CI 自动构建和基本验证 | 日常使用首选 |
| **Preview** | 不含 pre-release 标记的版本，比 Beta 更收敛 | 想尝鲜又偏好稳定 |
| **正式版（Release）** | 发布频率最低，经过完整测试 | 对稳定性要求极高的正式环境 |
| **Nightly** | 未经测试的 Debug 产物，直接由 net6 分支最新代码构建 | **仅用于测试，绝对不可用于正式课堂** |

> Nightly 构建在下载前需要阅读风险说明并勾选确认，且更新到下一个 Nightly 版本需要手动下载替换，不会自动更新。

## 安装版 vs 绿色版

| 对比项 | 安装版（.exe） | 绿色版（.zip） |
| --- | --- | --- |
| 安装方式 | 运行安装向导，自动完成 | 解压到任意目录即可 |
| 快捷方式 | 自动创建开始菜单和桌面快捷方式 | 需手动创建 |
| 写入系统 | 安装目录、注册表卸载项 | 完全不写系统 |
| 卸载 | 设置 → 应用 → 已安装的应用 → 卸载 | 直接删除文件夹 |
| 适用场景 | 个人电脑、班级一体机长期使用 | U 盘便携、机房批量部署、多版本并存 |

## 32 位还是 64 位？

- 现代设备一律选 **64 位（x64）**
- 仅在系统为 32 位、或需要与 32 位 Office 深度联动时选 **32 位（x86）**

## 安装后的目录结构

安装完成后，主程序和数据目录默认位于：

- **安装版**：`C:\Program Files\InkCanvasForClass CE\`（或自定义安装目录）
- **绿色版**：你解压到的目录

用户配置和墨迹数据保存在：

- **配置文件**：`%AppData%\InkCanvasForClass CE\Configs\Settings.json`
- **自动保存墨迹**：`%AppData%\InkCanvasForClass CE\Saves\`
- **截图**：`%USERPROFILE%\Pictures\Ink Canvas Screenshots\`
- **日志文件**：`%AppData%\InkCanvasForClass CE\Logs\`

## 升级

ICC-CE 内置在线更新检查。手动升级时：

- **安装版**：直接运行新版本安装包覆盖安装即可，配置与墨迹保留
- **绿色版**：解压新版本到旧版本程序目录覆盖即可

::: warning 跨通道切换
从 Beta 回退到正式版时，可能出现新版本写入的配置项无法被旧版本识别的情况。如遇异常，请备份后删除配置文件让程序重新生成。
:::
