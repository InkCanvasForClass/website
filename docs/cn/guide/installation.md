# 安装与更新通道

## 系统要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 版本 1809（build 17763）及以上、Windows 11 |
| 运行时 | **.NET 6 桌面运行时**（`net6.0-windows10.0.19041.0`） |
| 内存 | 建议 4GB 以上 |
| 显卡 | 支持 Direct3D 11 的显卡可启用硬件加速墨迹渲染 |
| 输入设备 | 触摸屏 / 数位板 / 鼠标均可，触控设备体验最佳 |

::: warning 关于 .NET 版本
主程序运行在 **.NET 6** 上，不是 .NET Framework 4.x。安装版会在需要时提示安装运行时；
绿色版若无法启动，多半是缺少 .NET 6 桌面运行时，请到微软官网下载 “.NET Desktop Runtime 6.x” 的 x64 或 x86 版本。

例外：手写识别所依赖的 IACore 组件只有 32 位版本，程序会额外启动一个 .NET Framework 4.7.2 的辅助进程来调用它。
这部分由安装包处理，通常无需手动干预。
:::

## 安装版还是绿色版

发布页同时提供两种形态，功能完全一致：

| | 安装版（`.exe`） | 绿色版（`.zip`） |
| --- | --- | --- |
| 安装方式 | 运行安装向导 | 解压到任意目录 |
| 开始菜单/桌面快捷方式 | 自动创建 | 需手动创建 |
| 卸载 | 控制面板卸载 | 直接删除文件夹 |
| 写入系统 | 是（安装目录、注册表卸载项） | 否 |
| 适用场景 | 个人电脑、长期使用 | U 盘便携、机房批量部署、多版本并存 |

::: tip 推荐
班级一体机等长期使用的设备建议用**安装版**；需要在多台机器间携带、或想同时保留多个版本时用**绿色版**。
:::

## 位数选择（32 位 / 64 位）

- 现代设备一律选 **64 位（x64）**
- 仅在系统为 32 位、或需要与 32 位 Office 深度联动时选 **32 位（x86）**

不确定时按 <kbd>Win</kbd> + <kbd>Pause</kbd> 查看“系统类型”。

## 四个更新通道

下载页的通道切换对应四类不同的构建来源：

| 通道 | 来源 | 包含 pre-release | 说明 |
| --- | --- | --- | --- |
| **Beta**（推荐） | `community-beta` 仓库 | ✅ | 更新最快、修复最及时，日常使用首选 |
| **Preview** | `community-beta` 仓库 | ❌ | 比 Beta 收敛，想尝鲜又偏好稳定时选它 |
| **正式版** | `community` 主仓库 | ❌ | 发布频率最低，稳定性要求极高时选它 |
| **Nightly** | GitHub Actions 构建产物 | — | **未经测试的 Debug 构建** |

::: danger Nightly 构建
Nightly 是 CI 从 `net6` 分支最新提交自动产出的 **Debug** 版本，没有经过任何测试，可能包含严重缺陷、崩溃或数据丢失风险。
**请勿在正式课堂环境使用。** 下载页会强制你阅读风险说明并勾选确认后才允许下载。
:::

### 为什么 Beta 通道的安装版来自主仓库

`community-beta` 仓库只发布绿色版 zip。下载页在该通道下找不到安装版时，会按**相同的版本 tag** 回到主仓库
`community` 取对应的安装版，并在按钮上标注「主仓库」。两者版本号一致，可放心使用。

## 下载加速

下载页启动时会并发探测两类线路，并在页面顶部显示结果：

- **智教联盟镜像**：国内直连速度较好，仅提供绿色版 zip。点击下载前还会再校验一次文件是否真的存在，不存在则自动回退
- **GitHub 加速镜像**：六个候选节点竞速，取最快的一个用于安装版与 API 请求；全部不可用时回退到 GitHub 官方直连

Nightly 的产物托管在 `nightly.link`，只能使用页面上列出的几个加速节点，可手动切换，选择会被记住。

## 升级

ICC-CE 内置在线更新检查，在设置中可配置检查频率与更新通道。手动升级时：

- **安装版**：直接运行新版本安装包覆盖安装即可，配置与墨迹保留
- **绿色版**：解压新版本到新目录，然后把旧目录下的配置文件与 `Saves` 文件夹复制过去

具体的数据目录位置见[配置文件与数据目录](/cn/guide/files-and-data)。

::: warning 跨通道切换
从 Beta 回退到正式版时，可能出现新版本写入的配置项无法被旧版本识别的情况。
如遇异常，请备份后删除配置文件让程序重新生成。
:::

## 卸载

- **安装版**：设置 → 应用 → 已安装的应用 → InkCanvasForClass CE → 卸载
- **绿色版**：直接删除整个文件夹

卸载不会自动清除用户配置与墨迹存档，需要彻底清理时请手动删除数据目录。
