# 配置文件与数据目录

<UnderConstruction />

## 目录结构

ICC-CE 的用户数据集中存放在数据目录下，典型结构如下：

```
数据目录/
├── Settings.json          用户设置（下载页、工具栏、手势等全部配置）
├── Saves/                 自动保存的墨迹存档
│   └── <演示文稿名>/       按演示文稿分目录
├── Logs/                  运行日志
└── CrashLogs/             崩溃报告
```

::: tip 快速定位
绿色版的数据目录通常就在程序所在文件夹内；安装版则位于用户目录下的应用数据文件夹中。
最可靠的办法是在设置界面中查找「打开数据文件夹」一类的入口。
:::

## Settings.json

所有设置项都序列化在这一个 JSON 文件里，按功能分区组织（画布、手势、形状识别、
PowerPoint、外观、启动、高级、自动化、安全等）。常用条目的说明见[设置指南](/cn/guide/settings)。

**手工编辑注意事项：**

- 编辑前请先完全退出 ICC-CE，否则退出时会用内存中的配置覆盖你的修改
- 保持 UTF-8 编码
- 键名大小写敏感，写错的键会被忽略而不是报错
- 改坏了可以直接删除该文件，程序下次启动会重新生成一份默认配置

## 墨迹存档

自动保存的墨迹写入 `Saves` 目录。保存位置由自动化相关的设置项控制，可以改到网络盘或 U 盘上。

::: warning 路径迁移
早期版本的文档中提到过其他保存路径，现已统一到 `Saves`。若你从旧版本升级，
旧目录中的存档不会自动迁移，需要手动复制过来。
:::

## 日志与崩溃报告

- **Logs**：记录启动、联动、识别等运行信息，排查问题时的首要参考
- **CrashLogs**：程序异常退出时生成，包含调用栈

反馈 Bug 时请附上对应时间点的日志文件，能大幅加快定位速度。日志中可能包含演示文稿文件名，
介意的话可在发送前自行删改。

## 备份与批量部署

**备份**：复制 `Settings.json` 与 `Saves` 目录即可。

**批量部署**：在一台机器上配置好之后，把 `Settings.json` 分发到其他机器的相同位置，
即可统一所有设备的工具栏布局与行为设置。配合绿色版可以做到整个文件夹直接拷贝。

::: warning 机房环境
部分机房使用还原卡或把安装目录设为只读。这种情况下请把数据目录指向不会被还原的分区，
否则每次重启都会丢失设置与墨迹。
:::
