# PPT 联动指南

<KnownBugs />

## PPT 联动模式

PowerPoint 放映时自动进入，无需手动操作。在此模式下：

- 工具栏上出现翻页按钮，可控制放映进度
- 在幻灯片上书写的墨迹按页自动保存
- 翻回已标注的页面时，墨迹自动恢复
- 放映结束后可回到普通模式继续编辑

> 联动不起作用？检查：PowerPoint 是否激活、是否处于保护模式（只读）、是否以管理员身份运行且 ICC-CE 未提权。

## 基础联动设置

| 设置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 启用 PPT 联动 | 开关 | 开启 | 检测到 PowerPoint 放映时自动启用标注 |
| 联动模式 | 选择 | COM | COM / ROT / Agent 三种联动方式 |
| 启用 WPS 支持 | 开关 | 关闭 | 启用 WPS 演示联动 |
| 关闭 WPS 进程 | 开关 | 开启 | 自动关闭 WPS 残留进程 |
| 智能模式 | 开关 | 关闭 | 智能识别并切换最优联动模式 |

## 常见问题排查

1. 确认 PowerPoint 已激活，不是保护模式/只读模式
2. 检查 ICC-CE 设置中 PPT 联动已开启
3. 检查 PowerPoint 是否以管理员身份运行，而 ICC-CE 未提权
4. 若同时使用 WPS，尝试关闭 WPS 支持或开启智能模式
5. 尝试切换联动模式（COM / ROT / Agent）
