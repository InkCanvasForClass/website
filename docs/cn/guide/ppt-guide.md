# PowerPoint 联动指南

ICC-CE 可以在放映幻灯片时随讲随写，并把每一页的墨迹分别记住。

## 三条联动通路

ICC-CE 并不依赖单一方式与 PowerPoint 通信，而是按可用性依次尝试：

| 通路 | 原理 | 何时生效 |
| --- | --- | --- |
| **COM 自动化** | 直接创建 PowerPoint 应用程序对象 | 最常规的情况，PowerPoint 正常启动即可 |
| **ROT / OLE** | 从运行对象表中获取已存在的 PowerPoint 实例 | COM 创建失败、或 PowerPoint 由其他程序先行启动时 |
| **VSTO 加载项** | 由加载项主动把放映事件推送给 ICC-CE | 前两者被安全策略拦截，或需要更及时的翻页事件时 |

程序会自动选择可用的一条，无需手动切换。若三条都不可用，工具栏中的 PPT 相关按钮不会出现。

## 安装 VSTO 加载项

加载项不是必需品，但能显著提升翻页事件的实时性。安装步骤：

1. 完全退出 PowerPoint 与 ICC-CE
2. 在 ICC-CE 设置中找到 PowerPoint 相关分区，启用加载项支持
3. 重新启动 PowerPoint，在「文件 → 选项 → 加载项」中确认 ICC 加载项处于启用状态

::: warning 加载项被禁用
Office 有时会因为启动缓慢而自动禁用加载项。若发现联动失效，请到
「文件 → 选项 → 加载项 → 管理：禁用项目」中把 ICC 加载项重新启用。
:::

## 放映时的行为

进入幻灯片放映后：

- 工具栏会出现**上一页 / 下一页 / 页码**等 PPT 专属按钮
- 在幻灯片上书写的墨迹按**页码**分别保存在内存中
- 翻页时自动收起当前页墨迹、恢复目标页墨迹
- 退出放映时，可根据设置自动把整份演示文稿的墨迹存盘

::: tip 翻页与撤销
翻页动作本身不进入撤销栈。误翻页请用工具栏的翻页按钮回到原页，墨迹会自动恢复。
:::

## 墨迹的保存位置

放映过程中产生的墨迹默认保存在数据目录下的 `Saves` 文件夹中，按演示文稿名称分目录存放。
保存路径可在设置中通过自动保存相关选项调整，详见[配置文件与数据目录](/cn/guide/files-and-data)。

::: warning 演示文稿改名
墨迹是按演示文稿名称关联的。重命名 pptx 文件后，之前保存的墨迹将无法自动匹配到新文件。
:::

## 常见问题

**放映了但工具栏没有出现 PPT 按钮**
说明三条通路都没连上。请确认 PowerPoint 是桌面版（非 UWP / 网页版），并检查杀毒软件是否拦截了 COM 调用。

**翻页时墨迹串页**
多见于同时打开多份演示文稿的场景。请只放映一份，或退出后重新进入放映。

**墨迹没有自动保存**
检查设置中自动保存是否开启，以及目标目录是否有写入权限（部分机房把安装目录设为只读）。
