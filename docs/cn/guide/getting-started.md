## 系统要求

- <badge type="tip" text="操作系统" /> Windows 10 1809（build 17763）及以上 / Windows 11
- <badge type="warning" text="运行时" /> **.NET 6 桌面运行时**（不是 .NET Framework 4.x）
- <badge type="tip" text="内存" /> 建议 4GB 以上
- <badge type="info" text="硬件" /> 支持触控输入的设备（推荐，但非必需）

完整的要求与通道说明见[安装与更新通道](/cn/guide/installation)。

## 安装

在[下载页](/cn/download)选择更新通道后，有两种形态可选：

- **安装版（`.exe`）**：运行安装向导，自动创建快捷方式，适合长期使用的设备
- **绿色版（`.zip`）**：解压到任意目录后运行 `InkCanvasForClass.exe`，不写入系统，适合便携与批量部署

首次运行时，软件会引导你完成初始设置。

::: warning 启动失败
双击没反应或一闪而过，通常是缺少 .NET 6 桌面运行时。到微软官网下载
“.NET Desktop Runtime 6.x” 对应位数的版本安装即可。
:::

## 基本操作

### 浮动工具栏

启动后会看到一个浮动工具栏，用于切换绘图工具与打开设置。

![浮动工具栏](https://github.com/user-attachments/assets/f47e80a8-05b8-44ab-8c70-6771e97375ea)

工具栏提供以下核心功能：

- 笔工具：自由绘制，支持压感
- 荧光笔：半透明标记
- 橡皮擦：按笔画擦除或圈选擦除
- 颜色选择：更改笔和荧光笔颜色
- 撤销 / 重做
- 设置：访问应用程序设置
- 收起 / 展开：最小化工具栏

### 两种绘图模式

1. **透明模式**：在任何应用程序或桌面上直接标注，适合屏幕批注
2. **白板模式**：提供专用绘图空间，适合板书与数学演算

点击工具栏上的模式按钮即可切换。

### 手势操作

触控设备支持双指缩放、双指平移、双指点击撤销等手势。
完整列表与防误触设置见[手势与快捷操作](/cn/guide/gestures-shortcuts)。

### 保存

- 截屏：把当前视图连同墨迹保存为图像
- 自动保存：按设置周期性保存墨迹，位置见[配置文件与数据目录](/cn/guide/files-and-data)

## 与 PowerPoint 集成

ICC-CE 可以在放映幻灯片时随讲随写，并按页记住墨迹：

1. 启动 PowerPoint 并打开演示文稿
2. 进入幻灯片放映模式
3. ICC-CE 自动检测到放映状态，工具栏出现翻页等专属按钮
4. 书写的墨迹按页保存，翻页时自动切换

联动原理、加载项安装与常见问题见[PPT 联动指南](/cn/guide/ppt-guide)。
