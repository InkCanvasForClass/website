# 快速开始

<UnderConstruction />

ICC-CE（Ink Canvas for Class Community Edition）是一款免费开源的屏幕批注和白板软件，专为课堂教学和演示场景设计。它让你能够在任何软件界面（PPT、PDF、浏览器、视频等）上方实时书写标注，或切换到全屏白板模式进行板书。

## 快速安装

1. 访问 [下载中心](/cn/download) 下载最新版本
2. 选择 **安装版（.exe）** 运行安装向导，或下载 **绿色版（.zip）** 解压到任意目录
3. 启动程序，工具栏将浮动在屏幕边缘

> 详细安装说明请参阅 [安装与更新通道](/cn/guide/installation)。

## 一分钟上手

1. **启动程序**：双击桌面快捷方式或运行主程序
2. **开始书写**：在任意软件界面上方直接使用笔/手指书写
3. **切换工具**：点击工具栏上的笔、荧光笔、激光笔、橡皮擦切换工具
4. **改变颜色**：点击颜色按钮选择笔迹颜色
5. **清屏**：点击清屏按钮清除所有墨迹
6. **退出**：右键托盘图标 → 退出

> 完整使用指南请参阅 [使用说明](/cn/guide/instruction-manual)。
