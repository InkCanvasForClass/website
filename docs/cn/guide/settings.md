# 设置指南

<KnownBugs />

设置面板通过工具栏 → 工具箱 → 设置打开。所有设置项保存在 `Settings.json` 中，按功能分区组织。

## 1. 启动设置（Startup）

| 设置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| 开机启动 | 开关 | 关闭 | 登录 Windows 后自动启动 ICC-CE |
| 启动时收纳 | 开关 | 关闭 | 启动后自动隐藏浮动工具栏到屏幕边缘 |
| 快速启动 | 开关 | 关闭 | 优化启动流程，减少启动时间 |
| 启动动画 | 开关 | 关闭 | 首次启动时显示全屏欢迎页 |
| 自动更新 | 开关 | 开启 | 启用后台自动检查更新 |
| 静默更新 | 开关 | 关闭 | 在指定时间段内静默下载并安装更新，不打扰用户 |
| 静默更新时段 | 时间范围 | 06:00–22:00 | 允许静默更新的时间段 |
| 更新通道 | 选择 | 正式版 | Release / Preview / Beta |
| 更新包架构 | 选择 | 跟随系统 | 32 位 / 64 位 |
| 智能更新 | 开关 | 开启 | 智能选择更新时机，避免在教学过程中突然更新 |
| 崩溃处理 | 选择 | 显示对话框 | 静默重启 / 仅记录日志 / 显示崩溃详情对话框 |
| 遥测等级 | 选择 | 不上传 | 不上传 / 基础 / 扩展 |
| 窗口 Chrome 渲染 | 开关 | 关闭 | 启用 Window Chrome 渲染（实验性，需重启生效） |
