# 常见问题

## 安装与启动

**双击没反应 / 一闪而过**
最常见的原因是缺少 **.NET 6 桌面运行时**。请到微软官网下载 “.NET Desktop Runtime 6.x” 并按系统位数安装。
若仍然无法启动，查看 `CrashLogs` 目录中的报告。

**杀毒软件报毒**
ICC-CE 需要创建透明置顶窗口并读取触控输入，部分安全软件会误报。请从官方发布页下载并添加信任。
若不放心，可对照发布页的文件校验信息核验。

**32 位还是 64 位**
现代设备一律用 64 位。只有系统本身是 32 位时才选 32 位版本。

## 书写与显示

**写字有明显延迟**
依次尝试：确认设备驱动为厂商官方驱动、在设置中开启硬件加速墨迹渲染、关闭其他占用 GPU 的程序。
老旧设备可适当降低墨迹平滑强度。

**笔迹粗细不均匀**
这是压感生效的表现。不需要压感时可在设置中关闭压感响应，笔迹会变成均匀粗细。

**画完的形状自动变成了规整图形**
形状识别被触发了。不需要时可在设置中关闭形状识别，或改为需要长按才触发。

**多点触控失灵**
先确认设备支持多点触控（设备管理器中能看到 HID 兼容触摸屏），再检查设置中的手势开关是否被关闭。

## 手势与操作

**双指缩放不起作用**
检查设置中的手势总开关与缩放手势开关。部分老旧一体机的触摸驱动会把双指手势直接吞掉，
这种情况下需要更新触摸驱动。

**误触频繁**
开启掌压屏蔽（防误触）相关选项，并适当增大触摸判定阈值。

## PowerPoint 联动

**放映时没有出现 PPT 按钮**
确认使用的是桌面版 PowerPoint，且未被安全策略拦截 COM 调用。详见[PPT 联动指南](/cn/guide/ppt-guide)。

**墨迹没有被保存**
检查自动保存开关与目标目录的写入权限。

**加载项装了但没生效**
Office 可能因启动缓慢自动禁用了它，到「文件 → 选项 → 加载项 → 管理：禁用项目」中重新启用。

## 设置与数据

**设置改了但重启后失效**
多半是程序没有正常退出（被强制结束进程），配置来不及写盘。请用正常方式退出。
若目录只读（机房还原环境），需要把数据目录换到可写分区。

**想把设置同步到其他机器**
复制 `Settings.json` 到目标机器的相同位置即可，详见[配置文件与数据目录](/cn/guide/files-and-data)。

**改坏了配置怎么恢复**
直接删除 `Settings.json`，程序下次启动会重新生成默认配置。

## 版本与更新

**该用哪个通道**
日常使用选 **Beta**，追求稳定选 **正式版**，**Nightly 不要用于正式课堂**。
详见[安装与更新通道](/cn/guide/installation)。

**下载很慢或下载失败**
下载页会自动选择最快线路。若仍然失败，可换一个通道试试，或直接到 GitHub 发布页手动下载。

**能不能退回旧版本**
可以。在下载页用「上一版 / 下一版」翻到目标版本下载即可。跨版本回退时如遇异常，
备份后删除配置文件重新生成。

## 反馈问题

提交 Issue 时请附上：ICC-CE 版本号、系统版本、复现步骤、以及 `Logs` 与 `CrashLogs` 中对应时间的文件。
信息越完整定位越快。
