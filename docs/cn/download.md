# <i class="fa-solid fa-download"></i> 下载 InkCanvasForClass CE

在这里获取 ICC-CE 的各个版本。页面会自动检测**智教联盟镜像**与 **GitHub 加速镜像**，为你选择当前最快的下载线路。

::: tip 该选哪个通道？
- **Beta 版**（推荐）：更新最快、修复最及时，适合日常使用
- **Preview 版**：不含 pre-release，比 Beta 更收敛
- **正式版**：发布频率最低，适合对稳定性要求极高的场景
- **Nightly 构建**：未经测试的 Debug 产物，**请勿用于正式课堂**

各通道的详细差异见[安装与更新通道](/cn/guide/installation)。
:::
